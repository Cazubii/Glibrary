# F5 — Erros que ensinam

## Diagnóstico confirmado
- Nove grupos de handlers em `src/main/ipc/` criam respostas de falha com o texto original de `Error.message`; o handler de assets também expõe mensagens de validação Zod diretamente.
- `IpcResult<T>` em `src/shared/types.ts` hoje restringe `error` a `string`; o renderer desembrulha a resposta em `src/renderer/src/lib/api.ts` e transforma a falha em `Error`.
- `App.tsx` mostra avisos simples por cinco segundos, sem título, próximo passo, detalhes recolhidos ou ação contextual.
- Os serviços de GitHub já reconhecem autenticação expirada, mas ainda devolvem uma string; o Git e as CLIs produzem mensagens diversas.

## Escopo
1. Criar `src/main/services/error-translator.ts` com tradução segura para autenticação, conflito, permissão, pasta existente, ferramenta ausente no PATH, rede, limite da API e token expirado.
2. Cada resposta traduzida terá título, resumo, próximo passo e detalhes técnicos sanitizados. Ações da interface serão incluídas somente quando existe destino claro no app.
3. Preservar o envelope IPC `{ ok: true, data } | { ok: false, error }`; `error` aceitará string legado ou a forma estruturada nova.
4. Adaptar o desembrulho do renderer e os avisos para exibir recuperação em português, ação contextual e detalhes técnicos recolhidos.
5. Cobrir os oito grupos com amostras de Git/GitHub/CLI sem dados pessoais.

## Fora do escopo
- Alterar permissões OAuth ou criar novos escopos.
- Tentar repetir operações automaticamente ou prometer que uma ação foi corrigida.
- Traduzir logs de execução ao vivo do agente; os avisos de falha de operações IPC são o alvo desta frente.
