# Segurança

Não publique vulnerabilidades, credenciais, tokens ou dados de usuário em issues públicas.

Use a opção **Report a vulnerability** na aba Security do repositório, se estiver habilitada.
Se ela não estiver disponível, use um canal privado de contato publicado por um mantenedor. Se
nenhum canal estiver listado, peça uma forma de contato privado sem revelar detalhes técnicos da
vulnerabilidade. Inclua passos de reprodução e impacto no relato privado; não anexe dados pessoais
nem segredos reais.

O suporte de segurança para versões é definido pelos mantenedores conforme releases publicados.
