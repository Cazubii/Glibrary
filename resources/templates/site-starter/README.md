# Meu primeiro site

Este é um site simples para você começar a experimentar com um assistente de IA.

## Ver o site

Abra `index.html` no navegador. O projeto não precisa instalar programas para mostrar a primeira página.

## Pedir uma mudança

Na receita do Glibrary, escolha um assistente e use um pedido como: “Troque as cores para azul e adicione uma seção de contato”. Depois, revise os arquivos que ele alterou.

Os arquivos principais são:

- `index.html`: o conteúdo da página;
- `style.css`: cores, tamanhos e organização;
- `script.js`: pequenos comportamentos da página.
